# Bengaluru Air Intelligence

An interactive air-quality monitoring and forecasting application for Bengaluru, combining historical AQI forecasting, live city-level air-quality estimates, station intelligence, and citizen-focused insights.

## Project Overview

The application contains four dashboards:

1. **Station Forecasting** – Historical monitoring-station AQI forecasting.
2. **Live Bengaluru AQI** – Live city-centre air-quality estimates and hourly forecasts.
3. **Station Intelligence** – Station-level information, freshness monitoring, and comparisons.
4. **Citizen Insights** – AQI rankings, charts, hotspot mapping, pollutant comparisons, and descriptive insights.

## Data Sources and Important Distinctions

### Historical Station Dataset
- Historical AQI and weather dataset.
- Original modelling dataset covers 13 monitoring stations.
- Historical data ends on 17 October 2026.
- Used for station-level forecasting experiments.

### Live City-Level AQI
- Provider: Open-Meteo Air Quality API.
- Location: Bengaluru city centre.
- Coordinates: 12.9716, 77.5946.
- Includes US AQI, PM2.5, PM10, and hourly forecast records.

**Important:** Live city-level AQI values are modelled estimates, not direct physical monitoring-station measurements. They are separate from the historical station forecasting models.

### Live Station Information
The application also includes a live station information dataset obtained through an external API provider. Availability and station coverage may vary.

## Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/Bengaluru_Air_Intelligence.git
cd Bengaluru_Air_Intelligence
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python app.py
```

Open the local Gradio URL displayed in the terminal.

## Data Limitations
- Historical station data ends on 17 October 2026.
- Historical station observations are not automatically updated.
- The dashboard displays data freshness warnings where applicable.
- The 1-hour and 6-hour forecasts use persistence baselines.
- The 24-hour station forecast uses Enhanced XGBoost.
- Future weather forecast inputs are not integrated into the trained 24-hour station model.
- The live city-level forecast is an external modelled forecast, not a prediction generated by the trained station-level XGBoost model.
- Live station availability depends on the external data provider.

## Project Goal
The goal is to make Bengaluru air-quality information easier to understand through forecasting, station-level analysis, interactive maps, and citizen-friendly visualizations.
